## Not built, or changed from the spec

- Real device runs (iPhone Safari, Android Chrome) were not possible here: the tests use Chromium phone emulation. The airplane-mode and background-tab tests simulate those states; please repeat them on a real phone.
- The Slack message was not sent against a real webhook here (no `SLACK_WEBHOOK_URL` locally). The text comes from `buildRoundSlack` in `src/lib/rounds.ts`.
- Items take an optional `label` (short name for the review screen and export). The Round 1 config in the repo has labels on the lines, faith, page name and anything-else items so the export matches the spec's short headings. The config is otherwise exactly the one in the spec.
- Intro note and done note are stored inside the round's config JSON (the admin fields write into it), not as separate columns.
- A reopened round shows the "Round N is ready" card on the client home again, so the client can find it.
- `round-opened` is logged when you open the round from admin; the client's progress is logged as `round-screen-viewed` per screen.
- Pinch zoom in the viewer is the browser's own zoom (the viewport allows it). Tapping the image doubles it; long images scroll inside the viewer; the X, Escape and the back gesture close it.
- `playwright` was added as a dev dependency so the tests can be rerun with `npm install`. It does not download browsers on install.
- Text boxes now also commit what was typed when the page is hidden, so switching apps mid-word on a phone does not lose the last few words.

## Review pass (October 18, evening)

Reran `npm run check`, `astro build` and both suites (8 of 8, 12 of 12), then went through every round screen on a 390 px phone with the real Round 1 images. Fixed:

- **Send is now one atomic step.** The lock is part of the database write: a save that races a Send can't land after it, and two Sends at once (double tap, two devices) give one send and a 409. Checked with three Sends fired together: 200, 409, 409.
- **Viewer and the back gesture.** The viewer pushed a fresh history entry every time the page re-rendered behind it (the save indicator flipping, a toast), so after closing it the next back swipe did nothing. It now pushes exactly one.
- **Short screens stretched.** On "Anything else" the extra height went into the rows, so the Round 1 pill became a tall oval with big gaps. Pages now stack from the top.
- **Upload all at once** on the round admin page: pick all 16 images together and each goes to the row with its name. Files not in the config are skipped and listed. The single-row Upload and Replace buttons still work.
- **Round gate copy:** "Enter the same code you use for your blueprint to open Round 1..." so the client doesn't look for a new code in the round email.
